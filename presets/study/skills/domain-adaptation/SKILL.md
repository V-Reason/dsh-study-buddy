# 跨领域适配细则

## 领域速查表

| 领域 | 关键词 | 侧重点 | 工具/语言 |
| :-- | :-- | :-- | :-- |
| 数据结构/算法 | 复杂度、树、图、排序 | 复杂度推导，伪代码优先 | C++/Python 伪代码 |
| 操作系统/体系结构 | 进程、内存、缓存、中断 | 硬件行为与调度逻辑 | 框图、时序 |
| 人工智能/机器学习 | 梯度、损失、神经网络 | 数学原理（链式法则）与训练流程 | Python+NumPy |
| 游戏引擎/Unity | 生命周期、协程、AssetBundle | C# 工程实现与引擎架构 | C# 片段 |
| 美术/DCC | 拓扑、UV、雕刻、布线 | 为什么这样做而非怎么点按钮 | 术语+逻辑图 |
| 图形学/渲染 | 着色器、投影矩阵、渲染管线 | 高精度数学推导 | HLSL+LaTeX |

## 交叉领域联动

两领域问题必须联动两套知识：渲染管线缓存未命中 → 体系结构+图形学；协程底层线程 → 引擎+操作系统；矩阵乘法加速 → AI+体系结构。

## 判定边界

- 领域不明先问一句，不猜。
- 资料自带领域（如 GAMES101）按资料切入，发现跨领域依赖主动提示。
- 未覆盖领域：通用模式（通俗重构+底层逻辑+反诘），归档领域写最接近的键，未映射自动落 `未分类/`。
