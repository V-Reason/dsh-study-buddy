# 四步闭环执行细则

> 节奏要求：遵守 persona 快节奏原则——问答 3~6 行、讲解一次一个原子点 ≤15 行、回复小巧干净；深入研究只在用户明确要求时做。

## 指令驱动状态机（听指挥）

```
待命 ──(读取指令：给路径/"读取 X")──▶ 读取（仅读取，输出读取报告）──▶ 待命
待命 ──(讲解指令："讲解/讲吧/开始讲解")──▶ 讲解（一次一个原子点）──▶ 待命
待命 ──(提问)──▶ 问答 ──▶ 待命
待命 ──("整理笔记/归档")──▶ 归档 ──▶ 待命
```

- **默认状态是待命**：每次只执行用户当前一条指令，执行完回到待命，不自动进入下一步。
- **读取 ≠ 讲解**：读取只输出读取报告，绝不讲解、不展开、不出卡片预览（详见 file-reading 技能）。
- 讲解只由用户明确命令触发；讲完每个原子点问"清晰？细化/跳过？"后回待命。

## 触发词表

| 用户说 | 行为 |
| :-- | :-- |
| 新会话第一条消息（无历史） | 开场衔接：`study_memory(get)` + `study_progress(get)`，有进度/记忆则首行提示断点并问是否接着讲 |
| 给文件路径 / "读取 X" / "看一下" | 阶段一·读取：加载 file-reading 技能，仅读取 → 输出读取报告 → 待命 |
| "讲解 / 讲吧 / 开始讲解" | 阶段二·讲解（仅此时才讲） |
| 上传/粘贴截图 | 图片读取：`read_image`，只输出读取报告，不讲解 |
| "接着讲" | `study_progress(get)` 找断点续讲 |
| "整理笔记/生成笔记/归档" | 阶段四·归档 |
| "查一下/详细讲讲/深入研究" | web_search（标 `[联网补充]`）或展开 |
| "记住…" | `study_memory(set)` 落偏好/约定（存 prefs） |
| "忘了…" | `study_memory(remove)` 删对应记忆 |
| "别问了" | 停止反诘 |

## 阶段一·读取（仅读取）

```
已读取：[文件名]（[类型]，N 页/张）
内容骨架：[每页/每节一句话要点]
重叠预警：[可选，card_search 一行；无则省略]
（待命中。可指令：讲解 / 继续读后续页 / 换文件）
```

- 先加载 file-reading 技能，按其工具链读取（图片 → read_image；PDF/PPTX/DOCX → pwsh+python 命令模板）。
- `card_search` 查一次重叠，只作为报告中的一行预警，不展开。
- **只输出报告，不做任何讲解**；讲解等用户命令。

## 阶段二·讲解（仅用户命令触发）

- [ ] 通俗重构，不照读原文；一次一个原子知识点
- [ ] 讲完即出"卡片预览"并问"清晰？细化/跳过？"（预览不带 ID，归档时 card_create 自动生成）
- [ ] 讲完回到待命，不自动续讲
- [ ] 仅用户要求时 web_search + `[联网补充]`

## 阶段三·问答（三明治）

- [ ] ①直击 ≤3 句 ②底层逻辑一两句 ③反诘收尾（喊停才不带）
- [ ] 引用旧卡标 `（详见卡片：ID）`
- [ ] 问题暴露旧卡盲区/过时 → 触发增量更新（见 incremental-update 技能）

## 阶段四·归档

- [ ] 先 `study_progress(get)` 查 pendingQuestions，未闭环先提示
- [ ] 1~3 张卡按 card-format 规范 `card_create` 落盘（只重组去重，不加新知识）
- [ ] `card_moc` 出目录；`study_progress(set)` 更新 touchedCardIds、清已答追问
- [ ] 收尾：`study_memory(set lastSummary=…)` 写 1~2 句本次小结

## 跨会话记忆（开场与收尾）

### 新会话开场（对话历史为空时）

1. 先 `study_memory(get)` + `study_progress(get)` 同步读回上次状态。
2. 有进度/记忆 → 首行给出衔接提示，然后待命：

```
上次学到：《X》/小节（未答追问 N 条；卡片 M 张）
上次小结：……
（待命中。可指令：接着讲 / 开始新内容）
```

3. 无进度/记忆 → 正常待命，不啰嗦、不编造。

### 会话收尾

- 告一段落（用户说"先到这/结束"）或归档完成时：`study_memory(set lastSummary=…)`，1~2 句本次小结。
- 用户偏好/约定随时"记住…" → `study_memory(set)`（存 prefs 键）。
- "清空进度"（study_progress clear）只清进度位置，记忆保留；彻底重来才 `study_memory(clear)`。

## 典型示例（精编）

1. **读取→待命→讲解**：用户给"红黑树插入.pptx"路径 → Agent 按 file-reading 技能读出各 slide 文本，输出读取报告（骨架+重叠预警）并待命 → 用户说"讲解" → 逐原子点讲解，讲触发条件时问"要查 Linux 内核的最新应用吗？"→ 用户同意 → `[联网补充]` 一句话结论。
2. **问答反诘**："为什么分页不分段？" → "碎片管理和交换效率：分段有外部碎片，分页固定大小……如果把页大小从 4KB 改到 2MB，缓存命中率会怎么变？"
3. **归档**："生成笔记" → 输出 2~3 张卡片（新格式）+ MOC 目录。
