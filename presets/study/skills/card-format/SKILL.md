# 阶梯式解剖卡片格式（定稿）

**知识即卡片**：卡片与普通笔记同库、同目录；旧笔记可原地升级（card_update replace 保留历史）。

**为什么是"阶梯式解剖"**：二次复习时先 30 秒抓住核心思想，再逐层下钻（直觉 → 机制 → 细节推导 → 边界），最后用自测题自检——一张卡就是一份可独立复习的"解剖标本"，不下于 400 字正文（目标 600~1500 字），不用再回到原资料。

## 模板

```markdown
---
ID: [YYYYMMDDHHmm_随机，工具自动生成]
标题: [概念名称]
领域: #图形学（可多标签）
来源: [资料名称]
状态: 草稿 / 已确认 / 需更新
---

> 一句话定义（≤30 字最佳，≤60 字硬上限；裸引用块，不加标题）。

### 核心思想

**一句话讲清**：<因果本质>
**为什么**：<它解决什么问题 / 为什么重要>
**记忆锚点**：<口诀或类比，一句>

### 阶梯式解剖（第 1 层 → 第 4 层）

**第 1 层 · 直觉**：<生活类比或一句话模型>

**第 2 层 · 机制**：<组件 / 流程 / 公式（块级 LaTeX 编号）；表格或代码（标语言）>

**第 3 层 · 细节与推导**：<为什么成立 / 假设前提 / 数字代入>

**第 4 层 · 边界与反例**：<适用条件 / 失效场景 / 易混淆对比>

### 实例走查

<代入具体数字/代码，标注步骤，一步步走完>

### 易错点

- <坑>：<为什么错>
- <坑>：<为什么错>

### 自测题

- **Q1**：<问题> → <答案要点一行>
- **Q2**：<问题> → <答案要点一行>

### 关联卡片

- 前置：`xxx`（来源/章节注释可省略）
- 后续：`yyy`、`zzz`
- 易混淆：对比说明
```

规则：
- **五小节必含**（核心思想 / 阶梯式解剖 / 实例走查 / 易错点 / 自测题），归档前补齐；缺一节 = 卡片未达标（校验会警告，persona 硬强制补齐）。
- **阶梯式解剖四层顺序固定**（1→4 不跳层）；每层至少一句话，可以"薄"但不得为空。
- **定义 ≤60 字硬上限**（工具 >60 直接拒绝并回显改写建议）；**30 字左右为 TL;DR 最佳**（检索契约），31~60 字**允许放行、不返工**（工具只做等级化提示）。仅修定义用 `card_update(definition)`——字段级微调，不重传正文、不产生历史折叠。「核心思想」从定义打开，不复述定义。
- 自测题 2~3 题，答案一行要点，**不复制正文**（防臃肿）。
- 单卡正文（不含定义/关联）≥~400 字为底线，目标 600~1500 字；过简先补充再归档。
- **标题**避免 `/ \ : * ? " < > |` 与引号（会被清洗）；实际文件名以 `card_create`/`card_moc` 返回的路径为准，不要按标题猜文件名。
- 公式块级 LaTeX 编号；代码标语言 hlsl/cpp/csharp/python/plaintext；frontmatter 后空一行再写定义；不加尾部标签行。

## 关联旧笔记（无 ID 的 .md）

检索命中里 `类型：旧笔记` 的目标没有卡片 ID，关联时用其**根限定路径**寻址：

- `card_link` 卡片↔旧笔记：默认只写卡片侧（旧笔记不碰不动），卡片侧写作
  `- 后续：旧笔记标题（工作目录/相对路径.md）`；
- 旧笔记↔旧笔记：默认拒绝，需 preset `linkIntoNotes: true`（写入旧笔记「### 关联卡片」小节）
  或改用 Obsidian 内链 `[[笔记名]]` 手动连接；Obsidian 会自动生成反向链接。
- 提到旧笔记时标注 `（详见旧笔记：<根>/<相对路径>）`，不要当作卡片引用（无 ID）。

## 完整样张

````markdown
---
ID: 202608161430_xyz
标题: 光线与表面的两种交互：散射与吸收
领域: #图形学
来源: 《Unity Shader入门精要》6.1.2
状态: 已确认
---

> 光线与表面相交只有两种结果：散射只改方向，吸收只改能量/颜色，二者不互相转换。

### 核心思想

**一句话讲清**：光线碰到物体只做两件事——改变方向（散射）或损失能量（吸收），所有光照模型都是这两者的加权组合。
**为什么**：把"看起来怎样"拆成"方向"与"颜色"两个独立变量，才有漫反射、高光这些可独立建模的分量；不理解这点会背公式而不懂物理来源。
**记忆锚点**：散射=换轨道，吸收=减预算；"先减钱还是先换路"决定了颜色与方向的耦合关系。

### 阶梯式解剖（第 1 层 → 第 4 层）

**第 1 层 · 直觉**：想象打台球——撞库换方向（散射）；球被毛毡吃掉一部分动能（吸收）。台球不会"边换方向边变蓝"吗？会，但那是两者先后发生，不是一件事。

**第 2 层 · 机制**：

| 交互类型 | 改变       | 不变       |
| :------- | :--------- | :--------- |
| **散射** | 方向       | 密度、颜色 |
| **吸收** | 密度、颜色 | 方向       |

散射再二分：
- 向物体内部 → 折射 / 透射
- 向物体外部 → 反射

**第 3 层 · 细节与推导**：不透明物体的漫反射为什么"方向均匀、颜色改变"？
折射进入内部的光在颗粒间反复弹射，部分被吸收、部分重新射出表面：
1. 弹射方向随机 → 出射方向与入射无关（均匀分布）；
2. 某些波段被吸收 → 出射颜色只剩"逃出来"的波段。
同理可推高光反射：只发生在表面、直接反弹 → 方向集中（镜面方向）、颜色几乎不变。

**第 4 层 · 边界与反例**：
- 适用条件：宏观平面假设（表面比光波长大多倍）；没有"纯散射"或"纯吸收"的实际材质，只有占比不同。
- 易混淆：漫反射 vs 高光反射——物理来源不同（内部多弹射 vs 表面直接反射），不能按"亮不亮"区分。

### 实例走查

设入射白光按 70% 散射（方向均匀）+ 30% 吸收（红光波段被吸走一半）：
- 出射能量 = 70% × (100% − 红光被吸 50%) → 出射光偏青（红少蓝绿多）；
- 若改入射红激光：吸收只压红光 → 出射光显著变暗；
- 结论：同一材质对白光"偏青"、对红光"更暗"——先吸收后散射的顺序不可交换。

### 易错点

- **把"散射"说成"反射"**：反射只是散射向外部的那一半；向内部的叫透射/折射，方向结论完全不同。
- **用"亮度"区分漫反射与高光**：高光可以在暗面更亮；应按"方向是否集中 + 颜色是否保留"判断。
- **忘记颜色来自吸收**：以为"颜色是物体自己发光"——颜色 = 反射光谱中未被吸收的部分。

### 自测题

- **Q1**：为什么不透明物体的漫反射方向均匀，而高光方向集中？ → 漫反射是内部多次弹射后出射（方向随机化），高光是表面一次反弹（方向保持）。
- **Q2**：给"吸收"换一个不透明度更高的材质，颜色会怎么变？ → 更多波段被吸收，出射光更暗、颜色更深（饱和度通常提高）。
- **Q3**：散射+吸收能互相转化吗？ → 不能；二者不互相转换，只能并行发生。

### 关联卡片

- 前置：`辐照度与朗伯余弦定律`（基础光照模型 6.1）
- 后续：`漫反射模型（Lambert）`、`Phong/Blinn-Phong 高光`
- 易混淆：漫反射 vs 高光反射（物理来源不同）
````

## 存量旧卡

已存在的自由格式卡片**不自动改写**：检索、读取、增量更新照常；下次 `card_update replace` 整卡时按本模板重写（旧内容进历史折叠块）。
