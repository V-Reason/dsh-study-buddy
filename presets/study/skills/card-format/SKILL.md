# 原子卡片格式（定稿）

**知识即卡片**：卡片与普通笔记同库、同目录；旧笔记可原地升级（card_update replace 保留历史）。

## 模板

```markdown
---
ID: [YYYYMMDDHHmm_随机，工具自动生成]
标题: [概念名称]
领域: #图形学（可多标签）
来源: [资料名称]
状态: 草稿 / 已确认 / 需更新
---

> 一句话定义（30 字左右，裸引用块，不加标题）。

### 自由小节

推导、表格、公式（块级 LaTeX 编号）、代码（标语言 hlsl/cpp/csharp/python/plaintext）。

### 关联卡片

- 前置：`xxx`（来源/章节注释可省略）
- 后续：`yyy`、`zzz`
- 易混淆：对比说明
```

规则：frontmatter 后空一行再写定义；正文小节标题自己起（如"核心机制""物理来源（重点）"）；不加尾部标签行。

## 完整样张

````markdown
---
ID: 202608161430_xyz
标题: 光线与表面的两种交互：散射与吸收
领域: #图形学
来源: 《Unity Shader入门精要》6.1.2
状态: 已确认

---

> 光线与表面相交只有两种结果：散射只改方向，吸收只改能量/颜色，二者不互相转换。

### 核心机制

光线从光源射出后遇到物体，交互结果只有两类：

| 交互类型 | 改变       | 不变       |
| :------- | :--------- | :--------- |
| **散射** | 方向       | 密度、颜色 |
| **吸收** | 密度、颜色 | 方向       |

### 散射的二分去向

- **向物体内部** → 折射 / 透射
- **向物体外部** → 反射

### 漫反射的物理来源（重点）

不透明物体中，折射进入内部的光会在颗粒间反复弹射，部分被吸收、部分重新射出表面。此时出射光：方向与入射无关（均匀分布）；颜色改变（某些波段被吸收）。

### 光照模型的划分依据

| 光照项   | 物理来源           | 方向特性               |
| :------- | :----------------- | :--------------------- |
| 高光反射 | 表面直接反射       | 方向集中（镜面方向）   |
| 漫反射   | 内部多次散射后出射 | 方向均匀（各方向一致） |

### 关联卡片

- 前置：`辐照度与朗伯余弦定律`（基础光照模型 6.1）
- 后续：`漫反射模型（Lambert）`、`Phong/Blinn-Phong 高光`
- 易混淆：漫反射 vs 高光反射（物理来源不同）
````

## 落盘位置

领域→目录映射（图形学 → 游戏开发/图形学 等，见 preset 配置）；未映射落 `未分类/<领域>/`；旧笔记升级原地不动。
