# 原子卡片格式规范（定稿）

**知识即卡片，卡片即知识**：卡片与普通笔记同库、同目录，格式一致；旧笔记也是卡片，可原地升级（`card_update` 的 replace 模式保留历史版本）。

## frontmatter 模板

```markdown
---
ID: [时间戳 + 随机后缀，如 202608161430_ab12]
标题: [核心概念名称]
领域: #图形学（可多个标签）
来源: [资料名称，如"《Unity Shader入门精要》6.1.2"]
状态: 草稿 / 已确认 / 需更新
---
```

## 正文结构

1. **一句话定义**：frontmatter 后空一行，直接一个裸 `>` 引用块（不加"定义"标题），30 字左右讲清本质。
2. **正文小节**：自由 `### 标题` 组织——推导、表格、公式（块级 LaTeX 编号）、代码（标注语言 hlsl/cpp/csharp/python）。标题自己起，如"核心机制""散射的二分去向""漫反射的物理来源（重点）"。
3. **关联卡片**：末尾固定小节，标签用 `前置` / `后续` / `易混淆`；目标用反引号包起来，可附（来源/章节）注释。
4. 不加尾部标签行（状态已在 frontmatter）。

## 完整示例（定稿样张）

````markdown
---
ID: 202608161430_xyz
标题: 光线与表面的两种交互：散射与吸收
领域: #图形学
来源: 《Unity Shader入门精要》6.1.2
状态: 已确认

---

> 光线与表面相交只有两种结果：散射只改方向，吸收只改能量/颜色，二者不互相转换。

### 核心机制

光线从光源射出后遇到物体，交互结果只有两类：

| 交互类型 | 改变       | 不变       |
| :------- | :--------- | :--------- |
| **散射** | 方向       | 密度、颜色 |
| **吸收** | 密度、颜色 | 方向       |

### 散射的二分去向

- **向物体内部** → 折射 / 透射
- **向物体外部** → 反射

### 漫反射的物理来源（重点）

不透明物体中，折射进入内部的光会在颗粒间反复弹射，部分被吸收、部分重新射出表面。此时出射光：

- 方向与入射无关（所以**均匀分布**）
- 颜色发生改变（因为某些波段被吸收）

### 光照模型的划分依据

| 光照项   | 物理来源           | 方向特性               |
| :------- | :----------------- | :--------------------- |
| 高光反射 | 表面直接反射       | 方向集中（镜面方向）   |
| 漫反射   | 内部多次散射后出射 | 方向均匀（各方向一致） |

### 关联卡片

- 前置：`辐照度与朗伯余弦定律`（基础光照模型 6.1）
- 后续：`漫反射模型（Lambert）`、`Phong/Blinn-Phong 高光`
- 易混淆：漫反射 vs 高光反射（物理来源不同）
````
