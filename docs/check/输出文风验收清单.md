# 输出文风与自适应讲解验收清单

> 版本基线：v1.5.0 ｜ 适用：真实 DSH「学习伙伴」会话
>
> 自动化测试负责模式判断、状态持久化和提示词契约；本清单负责人工检查实际生成文本是否存在机械感、重复和信息泔水。

## 检查口径

- 先看内容是否有用，再看结构是否克制。
- 单一问题不出现多余标题；列表只承载真正的并列或步骤；表格只承载二维对照。
- 依赖、层级、状态、时序、数据流和复杂失败链优先用图；简单事实不为了图文感硬画图。
- 图示必须承载结构信息，图旁只解释关键边、触发条件和失效点，不逐节点复述。
- 笔记正文从唯一 H1 开始，H1 后接普通导语；引用块只放外部原文，不放在 H1 前充当重复摘要。
- 同一结论不在正文、列表、表格和结尾总结里反复出现。
- 正文不默认出现“90 秒口径”、面试问答或下一步邀请；用户明确要求时才单独生成。
- 读取报告与普通回复自然结束，不机械追加“待命中/可指令”。
- 自动模式默认不展示快速/详细标签；只有用户询问依据或判断存在歧义时解释一行。
- 不做主动复习提醒，不生成待复习队列。

## 反例与目标写法

反例：

> 真正值钱的是这条：引用不传递。这条坑值得讲三遍，因为报错和真因完全对不上。一句话收口：asmdef 是配置源，csproj 是执行清单，dotnet 是驱动 MSBuild 的手。

目标写法：

> Unity 的 asmdef 引用不传递。测试程序集只引用 Presentation 时，看不到 Foundation 中定义的 `Singleton<T>`，因此会同时报 `CS0012` 和 `CS0117`。asmdef 声明 Unity 的程序集边界，Unity 据此生成 csproj，dotnet 再通过 MSBuild 编译。

反例的问题是按“值得强调”组织内容，先评价再解释，最后用金句重复。目标写法直接给出条件、结果和因果链。

结构关系优先使用下列形式：

| 关系 | 形式 |
| :-- | :-- |
| 线性因果、短调用链 | `A → B → C` 或编号步骤 |
| 层级、依赖方向、分支 | Mermaid `flowchart` |
| 类、接口、继承与实现 | Mermaid `classDiagram` |
| 表、字段、主外键 | Mermaid `erDiagram` |
| 多方交互时序 | Mermaid `sequenceDiagram` |
| 状态迁移 | Mermaid `stateDiagram-v2` |
| 版本、里程碑和时间线 | Mermaid `timeline` 或紧凑文本时间线 |
| 多对象共同维度 | Markdown 表格 |

## 场景矩阵

| # | 输入 | 预期 |
| :-- | :-- | :-- |
| 1 | 对一个从未讲解、笔记库无相关主题的概念说“讲解” | 进入详细模式；一个完整知识单元；必要例子与边界；无强迫确认问题；无自动预览 |
| 2 | 对近期已学习且有相关笔记的主题再问 | 进入快速模式；保留关键机制；省略已掌握的基础推导 |
| 3 | 把最近接触改成 31 天前后再问 | 回退详细；不自动弹出复习提醒，用户追问时能解释依据 |
| 4 | 说“快速”后连续追问 | 本会话持续快速；不逐轮重复模式标签 |
| 5 | 说“详细”后问一个简单定义 | 本会话保持详细；仍不堆砌无关背景 |
| 6 | 说“自动” | 清除会话覆盖；下一主题重新按证据判断 |
| 7 | 输入“模式” | 显示当前会话模式、最近主题和最近判断 |
| 8 | 普通答疑 | 直接回答；机制与边界按需；最多一个追问 |
| 9 | 说“别问了”后继续提问 | 后续不再主动追问 |
| 10 | 讲解结束后不额外发令 | 默认没有笔记预览 |
| 11 | 说“看笔记预览” | 才生成预览，内容不重复讲解全文 |
| 12 | 读取一个文件 | 只出文件信息、骨架、图片事实和可选重叠预警；无机械待命尾注 |
| 13 | 在快速模式执行归档 | 正式笔记仍按《笔记期望.md》完整可读 |
| 14 | 两个相同 cwd 的新会话分别切换模式 | 手动覆盖互不影响；新会话默认自动 |
| 15 | 新会话直接问普通技术问题 | 不展示断点、不询问“接着讲”、不出现复习提醒 |
| 16 | 说“今天从哪继续” | 一个主线下一步、完成判据、简短并行线 |
| 17 | 问一个单点事实题 | 直接回答，不扩写成完整课程 |
| 18 | 说“从零讲清一个系统设计” | 即使近期有笔记也使用详细讲解 |
| 19 | 讲解依赖图、状态机或导表流程 | 选用最轻且准确的图；图旁只解释关键边、条件和失效点 |
| 20 | 重写一篇项目复盘 | H1 后接普通导语；主次由 H2/H3 表达；无重复摘要与默认 90 秒收尾 |
