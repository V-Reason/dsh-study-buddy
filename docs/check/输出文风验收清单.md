# 输出文风与自适应讲解验收清单

> 版本基线：v1.3.0 ｜ 适用：真实 DSH「学习伙伴」会话
>
> 自动化测试负责模式判断、状态持久化和提示词契约；本清单负责人工检查实际生成文本是否存在机械感、重复和信息泔水。

## 检查口径

- 先看内容是否有用，再看结构是否克制。
- 单一问题不出现多余标题；列表只承载真正的并列或步骤；表格只承载二维对照。
- 同一结论不在正文、列表、表格和结尾总结里反复出现。
- 读取报告与普通回复自然结束，不机械追加“待命中/可指令”。
- 模式变化只提示一次；没有变化时不反复显示模式。

## 场景矩阵

| # | 输入 | 预期 |
| :-- | :-- | :-- |
| 1 | 对一个从未讲解、笔记库无相关主题的概念说“讲解” | 进入详细模式；一个完整知识单元；必要例子与边界；无强迫确认问题；无自动预览 |
| 2 | 对近期已学习且有相关笔记的主题再问 | 进入快速模式；保留关键机制；省略已掌握的基础推导 |
| 3 | 把最近接触改成 31 天前后再问 | 回退详细模式；模式变化提示一行原因 |
| 4 | 说“快速”后连续追问 | 本会话持续快速；不逐轮重复模式标签 |
| 5 | 说“详细”后问一个简单定义 | 本会话保持详细；仍不堆砌无关背景 |
| 6 | 说“自动” | 清除会话覆盖；下一主题重新按证据判断 |
| 7 | 输入“模式” | 显示当前会话模式、最近主题和最近判断 |
| 8 | 普通答疑 | 直接回答；机制与边界按需；最多一个追问 |
| 9 | 说“别问了”后继续提问 | 后续不再主动追问 |
| 10 | 讲解结束后不额外发令 | 默认没有笔记预览 |
| 11 | 说“看笔记预览” | 才生成预览，内容不重复讲解全文 |
| 12 | 读取一个文件 | 只出文件信息、骨架、图片事实和可选重叠预警；无机械待命尾注 |
| 13 | 在快速模式执行归档 | 正式笔记仍按《笔记期望.md》完整可读 |
| 14 | 两个相同 cwd 的新会话分别切换模式 | 手动覆盖互不影响；新会话默认自动 |
