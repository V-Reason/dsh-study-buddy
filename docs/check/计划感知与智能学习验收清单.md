# 计划感知与智能学习验收清单

> 版本基线：v1.4.0 ｜ 适用：真实 DSH「学习伙伴」会话

## A. 计划入口

- [ ] 新会话直接问普通技术问题：不显示断点、不问“接着讲”、不出现复习提醒。
- [ ] 说“今天从哪开始 / 从哪继续 / 我回来了”：只出现一个主线动作、一个完成判据和简短并行线。
- [ ] 计划旧进度与当轮要求冲突：以当轮明确要求为准，不擅自改计划文件。
- [ ] 完整知识单元结束后：`phase/currentMaterial/currentSection/nextAction/doneWhen/lastOutcome` 合理收口。
- [ ] 中途追问或未完成项目动作：正式进度不推进。

## B. 意图驱动讲解

- [ ] 单点事实题直接回答，不扩写成完整课程。
- [ ] “从零讲清 / 系统设计 / 排错 / 比较”默认详细。
- [ ] “快速 / 详细 / 自动”手动覆盖有效，且只影响当前会话。
- [ ] 自动模式默认不出现“本次使用快速/详细模式”等标签。
- [ ] 没有相关笔记、没有接触记录或主题不确定时进入详细模式。

## C. 笔记维护

- [ ] “笔记体检”指定目录后返回聚合问题，不倾倒全库文件列表。
- [ ] 全库体检必须由用户明确确认后传 `path='.'`。
- [ ] 缺来源章节、缺微目录、孤立、断链、歧义链接、重复标题都能被识别。
- [ ] 修复前列出目标文件与字段；确认后只改来源章节/状态/微目录/明确 wikilink。
- [ ] metadata 修复前后正文逐字一致，未知 frontmatter 键保留。
- [ ] 修复原文进入 `.study/archive/`，可用 `note_history` 查看。

## D. 回归

- [ ] 工具总数仍为 19，无 `card_*`、无第 20 个学习工具。
- [ ] 快速与详细模式下归档的正式笔记完整度一致。
- [ ] 旧 `progress.json`、`memory.json`、`learning.json` 无需迁移即可读取。
- [ ] 快速/详细/自动不写成长期偏好，不生成待复习队列。
- [ ] `pnpm run check`、`pnpm run verify:contract`、`pnpm run verify:deploy -- -Profile web` 结果按实际记录。
