# 计划感知与智能学习实施计划

> 版本基线：v1.4.0 ｜ 状态：已实施 ｜ 需求：[`计划感知与智能学习-需求分析.md`](计划感知与智能学习-需求分析.md)

## 1. 执行原则

- 保持 19 个工具，扩展现有 action 与字段。
- 每项任务先写失败测试，再实现并跑 targeted tests。
- 旧 `.study` 状态只增加可选字段，不做迁移。
- 不加入主动复习提醒、出题或白板子系统。
- 笔记修复先存档、后原子写；正文必须逐字不变。

## 2. 任务

1. **计划上下文与简报**：新增 `studyBrief.ts`，扩展 `ProgressState` 和 `study_progress(action=brief)`。
2. **意图驱动模式**：为 `study_mode.resolve` 增加 `intent/scope`，显式覆盖优先，学习、应用、排错、比较和系统问题默认详细。
3. **可发现性审计**：新增纯函数 `discoverability.ts`，扩展 `note_library(action=audit)`；只读取 vault，必须明确目录。
4. **元数据修复**：新增 `applyMetadataUpdate()` 与 `note_update(action=metadata)`，只改来源章节/状态，保留未知键与正文。
5. **提示词接线**：persona、`study-loop`、`output-style`、`note-format` 与默认《笔记期望.md》改为静默开场、模式隐身、无复习提醒、体检需确认。
6. **文档与验收**：同步用户指南、设计/技术文档、更新记录、版本号 `1.4.0` 和验收清单。

